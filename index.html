From classroom demo to reliable application

Five workshops make the design decisions visible. Self-paced mode remains the default; the instructor-led tab is optional.

What is real: Lexical mode ranks chunks with weighted word overlap (TF–IDF-style). Embeddings mode runs the real all-MiniLM-L6-v2 sentence-transformer in your browser (384 dimensions, cosine similarity), downloaded once (~23 MB) and cached. What is not: no API key, no server, no live LLM. Retrieved passages are source excerpts, not generated answers, and similarity scores are ranking signals, not probabilities.
